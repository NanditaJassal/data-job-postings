# data-job-postings
SQL analysis of job postings, salary ranges, work arrangements and in-demand skills

Project Overview
This project explores job postings using SQL to identify trends in job titles, salary ranges, work arrangements, and in-demand skills.
The goal is to demonstrate practical SQL skills and data analysis techniques through a real-world-style data analytics project.

Objectives
Analyze the distribution of job postings by title.
Compare advertised minimum and maximum salaries across roles.
Explore remote, hybrid, and on-site work arrangements.
Identify frequently requested skills across job postings.

Tools & Technologies
MySQL — querying and analyzing data
DBeaver — SQL development environment
Google Sheets — initial data exploration
GitHub — version control and project documentation

SQL Analysis
The project includes queries using:
SELECT and DISTINCT
Aggregate functions such as COUNT() and AVG()
GROUP BY and ORDER BY
String processing and JSON_TABLE() to analyze skills

Dataset
The dataset contains job posting information, including job titles, seniority levels, locations, work arrangements, salary ranges, companies, and required skills.
